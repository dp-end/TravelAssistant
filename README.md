# Travel Assistant

AI-powered, bilingual (Turkish/English) travel-planning assistant built as a set of
containerised microservices (.NET 10, Python, PostgreSQL, Redis, RabbitMQ, React).

> Status: repository bootstrap in progress. Architecture, service skeletons, Docker
> Compose environment, CI/CD and contribution rules are being set up on the
> `chore/bootstrap` branch. See `docs/` once merged.

Akdeniz University, Department of Computer Engineering, CSE 491 graduation project (Group 24).
